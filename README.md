## Descripción General

Este repositorio contiene las prácticas desarrolladas durante el primer parcial de la materia Extracción del Conocimiento de Base de Datos.

Se realizaron actividades de análisis de datos utilizando datasets reales, aplicando técnicas de limpieza, transformación, visualización e interpretación de información para generar conocimiento mediante el modelo DIKW (Datos, Información, Conocimiento y Sabiduría).

---

## Objetivo

Desarrollar un repositorio académico en GitHub que integre: limpieza de datos, análisis descriptivo, visualización de datos, interpretación de resultados, y generación de conocimiento mediante el modelo DIKW, utilizando un dataset público real.

El objetivo principal es evaluar: organización del proyecto, documentación, buenas prácticas, uso de GitHub, y capacidad de análisis e interpretación de datos.
